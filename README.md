# 🎄 크리스마스 기념 눈싸움 하자! — 친구랑 카메라 앞에서 1:1

**테마: 뉴욕의 크리스마스** — 밤하늘, 픽셀 뉴욕 스카이라인(계단식 타워 꼭대기 빨강·초록 조명), 록펠러 센터 같은 큰 트리(전구 반짝), 화면 위 꼬마전구, 계속 내리는 눈.
배경은 `shared/xmas.js` 가 모든 페이지에 그려요. 색은 `shared/ui.css` 맨 위 변수(빨강 `--pink`, 초록 `--green`, P1 빨강 / P2 초록)에서 바꿀 수 있어요.

웹캠 하나 앞에 친구랑 나란히 서서 하는 게임 두 개를 모은 웹앱입니다.
얼굴·몸 인식은 [MediaPipe](https://ai.google.dev/edge/mediapipe) 로 **브라우저 안에서만** 처리하고, 영상은 어디에도 저장하지 않아요.

## 실행

1. 폴더 안 **`start.bat` 더블클릭** → 브라우저에서 `http://localhost:8000` 이 열림
2. 카메라 권한 **허용**
3. 끄려면 검은 창에서 `Ctrl + C`

> Python이 필요해요. 없으면 https://www.python.org/downloads/ 에서 설치할 때 **Add python.exe to PATH** 체크.
> `index.html` 을 더블클릭해서 열면 카메라가 안 켜져요 (꼭 start.bat).

## 메인 홈 화면 (픽셀 UI)

| 위치 | 기능 |
|---|---|
| ❤️ 왼쪽 위 하트 | 게임당 하트 개수 (누르면 설정) |
| 🏆 트로피 | 캐릭터별 승/패 순위 + 최근 경기 |
| ⚙️ 톱니바퀴 | 하트 개수(1/3/5), 효과음, 포커페이스 모드·난이도, 눈덩이 라운드 시간, 기록 초기화 |
| 가운데 캐릭터 + ← → | 캐릭터 고르기 (LILY / ROSE / DAISY). 아래 **P1 / P2** 탭을 눌러 누구 캐릭터를 고를지 전환 |
| START | 게임 선택 (산타 포커페이스 / 크리스마스 눈싸움) |
| ✉️ 편지 | 게임 방법 |
| 👛 지갑 | 캐릭터별 코인 (승리 +10, 참가 +2) |

키보드: ← → 캐릭터 변경 · Tab P1/P2 전환 · Enter 시작

## 🎅 산타 포커페이스 (`pokerface/`)

- 두 사람이 나란히 앉으면 **왼쪽 얼굴 → P1 패널, 오른쪽 얼굴 → P2 패널** 에 각자 얼굴이 크게 뜸
- 3초 무표정 보정 → 3, 2, 1 → 시작
- 웃거나 눈을 깜빡이면 **하트 -1** (1.6초 쉬었다가 다시), 얼굴이 1초 넘게 사라져도 -1
- 방해 요소가 점점 세짐: 이모지 → 아재개그·화면 흔들림 → 얼굴 필터(왕눈이·피에로 코·콧수염) → 효과음
- 먼저 하트를 다 잃으면 K.O.
- 판정 조정: `pokerface/src/judge.js` 의 `DIFFICULTY`, 방해 문구 추가: `pokerface/src/data/jokes.js`

## ☃️ 크리스마스 눈싸움 (`snowball/`)

- 화면 가운데 선 기준 **왼쪽 P1 / 오른쪽 P2**
- ❄️ 내리는 눈에 손 대서 받기 → 🌀 손을 빙글빙글 돌려 키우기 → 💨 상대 쪽으로 팔을 휙! 던지기
- 😎 내 얼굴에 빨간 조준점이 뜨면 몸을 움직여 피하기 · 맞으면 **하트 -1**
- 큰 눈덩이일수록 ⭐ 점수가 크지만 느리게 날아감
- 하트를 다 잃거나 시간이 끝나면 종료 (하트 → ⭐ 순으로 승부)
- **혼자 연습** 모드: 눈사람 봇이랑 대결 (코인 없음)
- 판정 조정: `snowball/src/game.js` 맨 위 `CFG` (던지기가 잘 안 되면 `throwSpeed` 를 0.8 정도로)

카메라에서 **2~3m** 떨어져 상체와 두 손이 다 보이게 서야 손 인식이 잘 돼요. 게임 중 **D 키** 를 누르면 인식 값이 보여요.

## 폴더 구조

```
face_game/
├── start.bat / server.py / package.json
├── index.html, home.css, home.js     # 메인 홈 (픽셀 UI)
├── shared/
│   ├── ui.css                         # 픽셀 테마 공통 스타일 (크리스마스 색)
│   ├── xmas.js                        # 뉴욕 크리스마스 배경 (밤하늘·스카이라인·트리·전구·눈)
│   ├── profile.js                     # 캐릭터·설정·기록·코인 (localStorage)
│   ├── camera.js, sfx.js              # 웹캠, 효과음
│   ├── assets/                        # UI 이미지에서 잘라낸 픽셀 에셋 (캐릭터, 아이콘, START 등)
│   └── fonts/                         # Galmuri11 픽셀 폰트 (OFL 라이선스)
├── pokerface/                         # 게임: 포커페이스 챌린지 (Face Landmarker, 2명)
├── snowball/                          # 게임: 눈덩이 대작전 (Pose Landmarker, 2명)
├── lib/mediapipe/                     # @mediapipe/tasks-vision 1.2.2
└── models/                            # face_landmarker.task, pose_landmarker_lite.task
```

## 캐릭터 추가하기

1. `shared/assets/` 에 배경이 투명한 PNG 캐릭터와 아이템 이미지를 넣고
2. `shared/profile.js` 의 `CHARACTERS` 에 한 줄 추가 (`itemW` 는 아이템 크기)
